# kube-agents-test — User documentation

This folder holds user-facing documentation for the **kube-agents-test** framework: high-level testing for the kube-agents platform, where multiple autonomous agents operate on a shared Kubernetes cluster.

The content here is derived from the project [design README](../README.md). It elaborates core concepts and behavior described there; it does not document APIs or implementation that do not yet exist in the repository.
